# GLYCAM Traefik V3 Proxy

This is the git repository for the GLYCAM Traefik V3 Reverse Proxy.

## Quick Start

```bash
git clone https://github.com/GLYCAM-Web/GLYCAM_Traefik_V3_Proxy.git

cd GLYCAM_Traefik_V3_Proxy

cp config.bash.example config.bash
chmod 600 config.bash
# Edit config.bash to set LE_EMAIL and GRAFANA_ADMIN_PASSWORD

## Optionally, if you want to do a dry run:
export TEST="YES"

bash start.sh
```

## Files and Directories List

### Contained herein

- `config.bash.example`

   Template for creating your local (git-ignored) `config.bash` with `LE_EMAIL`, `GRAFANA_ADMIN_PASSWORD`, and optional security/network settings (`TRAEFIK_API_INSECURE`, `TRUSTED_PROXIES`, `INTERNAL_IP_CIDRS`).

- `docker-compose.traefik.swarm.yml`

   YAML compose file used by Docker to deploy the Traefik Reverse Proxy and monthly access log rotator (`traefik-logrotate`) in Swarm.

- `docker-compose.logging.swarm.yml`

   YAML compose file deploying the centralized logging and analytics stack (`VictoriaLogs`, `Vector`, and `Grafana`). Deployed automatically by `start.sh` unless `export ENABLE_LOGGING_STACK="NO"` is set in `config.bash`.

- `logging/`

   Contains scripts and configurations for monthly log rotation, splitting/backfilling existing large `access.log` files, `Vector` log shipping, pre-provisioned `Grafana` AWStats-style and public dashboards, and `logging/internal_ips.example.conf` (template for git-ignored `logging/internal_ips.local.conf`). See `logging/README.md` for details.

- `.gitignore`

   List of file/directory patterns for git to ignore.

- `LICENSE`

   The license for the repo.

- `README.md`

   This file.

- `start.sh*`
- `stop.sh`

   Start or stop the service.

- `test-whoami.sh`

   A mechanism for testing the traefik installation.
   Note: restricted to localhost / RFC1918 private networks via Traefik `ipallowlist` middleware.

- `Examples/`

   These files are described in the README.md file in this directory.

    - `docker-compose.proxy.swarm.base.port.yml`
    - `docker-compose.proxy.swarm.traefik.https.yml`
    - `docker-compose.proxy.swarm.traefik.ratelimits.yml`

    - `README.md`

### You must create (git-ignored)

- `config.bash`

   Copy from `config.bash.example` (`chmod 600 config.bash`). Contains information needed at startup (`LE_EMAIL`, `GRAFANA_ADMIN_PASSWORD`, etc.).

- `logging/internal_ips.local.conf` *(optional)*

   Copy from `logging/internal_ips.example.conf` (created automatically by `start.sh` if absent). List internal lab routers, team static IPs, or VPN CIDRs (one per line) to exclude internal traffic from public usage statistics without committing private IP addresses to git.

### Created at startup, if not already present

- `acme/`

   Contains encryption info. This directory is made by the start.sh script.

    - `acme.json`

   The file that stores the encryption data for serving https.
   This file must be generated by Traefik. Getting it started can be a challenge.
   Please see the documentation for Traefik and Lets Encrypt for clarity.

   If it is not present at startup, the script will issue a warning and wait for your
   response. It's really important.

- `logs/`

   Logs from Traefik. Log rotation is enabled. This directory is created by start.sh.

    - `traefik.log`

       The current traefik log. Others should be time-stamped and compressed (gzip).
       Traefik will generate and maintain this file.

    - `./logs/start_STDOUT_${DATE}.log`
      `./logs/start_STDERR_${DATE}.log`
      `./logs/stop_STDOUT_${DATE}.log`
      `./logs/stop_STDERR_${DATE}.log`

       Logs written by this script upon startup or shutdown.

- `ACCESS_LOGS/`

    Logs of accesses from outside the swarm. Includes the name of the host requested.
    Monthly log rotation (`access-YYYY-MM.log.gz`, kept forever) is handled automatically by the `traefik-logrotate` service, and live logs are shipped to `VictoriaLogs` + `Grafana` by `Vector`. This directory is created by `start.sh`.

    - `access.log`

       The current month's active access.log created and maintained by Traefik.
    - `access-YYYY-MM.log.gz`

       Rotated monthly access log archives (compressed with gzip, retained indefinitely).
       See `logging/README.md` for details on splitting/backfilling existing large `access.log` files and using Grafana.
